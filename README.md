# Ansharah Yaqoob — Portfolio

A responsive personal portfolio inspired by the supplied pastel pink, mauve, and dark plum reference design.

## Included
- `index.html` — portfolio content and sections
- `style.css` — complete responsive styling and CSS portrait illustration
- `script.js` — mobile menu, reveal animations, theme toggle, and email form behavior

## Run
Keep all three files in the same folder and open `index.html` in a browser. No build tools are required.

## Sections
Home, About Me, Skills, Featured Projects, Learning Journey, and Contact.
